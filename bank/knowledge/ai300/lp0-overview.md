## Audience Profile

Candidates should have expertise in:
- Setting up MLOps and GenAIOps infrastructure on Azure (together = AIOps)
- Training, optimizing, deploying, and maintaining traditional ML models with Azure Machine Learning
- Deploying, evaluating, monitoring, and optimizing generative AI applications and agents with Microsoft Foundry
- Python programming background
- Entry-level DevOps: GitHub Actions, CLI tools
- Infrastructure as code (IaC) with Bicep and Azure CLI

## Key Services and Tools

- **Azure Machine Learning** — workspace, datastores, compute, MLflow, pipelines, endpoints
- **Microsoft Foundry** — model catalog, serverless endpoints, prompt flow, evaluation
- **GitHub Actions** — CI/CD workflows for ML automation
- **Bicep + Azure CLI** — IaC for workspace and Foundry provisioning
- **MLflow** — experiment tracking, model registration, versioning
- **Azure Monitor / App Insights** — observability for deployed models and GenAI apps
